# P0.10 — Final Settlement Lifecycle

## Contract

P0.10 expands the existing `calculate_final_settlement()` capability into a persisted final-settlement lifecycle. It does not create a competing settlement domain.

### Existing contract preserved

- `GET /api/final-settlement/<occupancy_id>/` remains unchanged.
- `calculate_final_settlement(occupancy_id, workspace)` remains the canonical settlement position/projection.
- Existing invoice, payment allocation, advance-credit, adjustment, late-fee and refund semantics remain unchanged.
- Security deposit remains separate from invoice settlement and payment allocation.

### Finalization

`POST /api/final-settlement/<occupancy_id>/settle/` finalizes the existing final-settlement position.

Rules:

1. Requester must be a workspace manager, admin, or owner.
2. Occupancy must belong to the requested workspace.
3. Occupancy must have a check-out date.
4. All invoice outstanding balances must be zero according to the canonical financial position.
5. Deposit outcome is explicit through `refundable_deposit`; omitted means the full deposit is refundable.
6. `retained_deposit + refundable_deposit == security_deposit`.
7. Final settlement is persisted as an immutable historical snapshot.
8. One final settlement exists per occupancy; retries return the existing settlement.
9. Finalization does not create a `PaymentRefund`; refund execution remains a separate future/provider-bound operation.
10. Finalization does not automatically mutate `Occupancy.is_active`.

### Historical snapshot

The persisted settlement stores total rent, total charges, total paid, total due, security deposit, retained deposit, refundable deposit, final balance, outcome, settlement actor and settlement timestamp.

### Canonical flow

`Existing Final Settlement Projection → Finalization Eligibility → Canonical Financial Transition → Immutable Final Settlement Snapshot → Future Refund/Reporting/Automation`

The settlement snapshot is not a second source of financial truth; it records the finalization event and the financial position at that moment.
